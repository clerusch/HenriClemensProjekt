\section{Research Roadmap}
We chart a four-year programme aligned with the Eisert--Preskill gap structure, ensuring each stage produces evidence that the transition is underway.

\textbf{Year 1: Certifying Heuristic Rewrites}
\begin{itemize}
  \item Formalise the ZXW rewrite catalogue and validate soundness proofs in Coq/Isabelle snippets, turning gap (iii) heuristics into auditable steps.
  \item Implement a QUIZX plugin that applies the new rules, emits certificate logs, and tags mitigation-aware metrics.
  \item Benchmark against Pauli-sum Hamiltonians and open QEC case studies to stress-test provenance tracking.
\end{itemize}

\textbf{Year 2: Feedback for Mitigation-to-Correction Handover}
\begin{itemize}
  \item Integrate flow and gflow heuristics that surface when mitigation plateaus, pointing to code-distance upgrades (gap (i)).
  \item Prototype classical feedback loops that co-optimise diagram simplification, numerical estimations, and error-budget projections.
  \item Package visual analytics dashboards for ZXW evolution, allowing collaborators to interrogate ``proof pockets'' before hardware deployment.
\end{itemize}

\textbf{Year 3: Credible Simulation and Hardware Reports}
\begin{itemize}
  \item Deliver gate-set and code-aware extraction stacks for two hardware partners with bespoke calibration and syndrome-readout playbooks.
  \item Run end-to-end experiments that trace results from domain models through mitigation, detection-ready circuits, and classical co-simulators (gap (iv)).
  \item Publish reproducible benchmarks, open-source tooling, and validation datasets that anchor cross-lab comparisons.
\end{itemize}

\textbf{Year 4: Fault-Tolerant Bridging and Dissemination}
\begin{itemize}
  \item Integrate the toolchain with early logical-qubit experiments to test scaling behaviour as error correction becomes active.
  \item Generalise certificate logs into shareable ``gap reports'' that quantify readiness levels for application-scale workloads.
  \item Consolidate outcomes into community tutorials, joint publications, and partner pilots that demonstrate progress across all four gaps.
\end{itemize}
